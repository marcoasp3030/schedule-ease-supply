# Supply Slot Scheduler

preciso que seja criado um sistema de agendamento de recebimento para fornecedores em anexo alguns exemplos das telas o usuario administrador poderar definir quantos agendamentos por dia poderar ser feitos, definir se poderar ter entregas aos finais de semanas, definir a partir de qual horario poderar o fornecedor fazer entregas inicial e final
